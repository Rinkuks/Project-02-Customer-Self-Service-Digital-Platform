# Project 02 — Customer Self-Service Digital Platform

## Executive Portfolio Case Study

A simulated project management case study demonstrating end-to-end process improvement and digital delivery governance.

### Project Objective

Define and deliver an MVP concept to reduce avoidable customer support interactions by improving customer access to status information, reducing waiting, and increasing visibility and ownership.

### Business Problem

Customer requests relied heavily on support channels for routine status and information needs.

Current-state analysis identified:

- 92-minute total lead time
- 64 minutes of waiting within the process
- 25% value-added processing time
- Manual status searching
- Repeated follow-up
- Fragmented information
- Multiple handoffs and rework

### Approach

The project combined Lean Six Sigma, Agile/Scrum, Jira and SDLC governance.

**Lean / Process Improvement**
- Customer Journey Mapping
- Value Stream Mapping
- Waste analysis
- A3 problem solving
- Future-state design

**Agile / Scrum**
- Improvement backlog
- Epic and user stories
- Jira work-item execution
- Sprint planning and execution
- Scrum status reporting
- Velocity reporting

**SDLC / PM Governance**
- Requirements and MVP scope
- Analysis and design
- Development planning
- Testing and verification
- UAT readiness
- Release readiness
- Lifecycle governance

### Future-State Target

The proposed future state reduced lead time from:

**92 minutes → 54 minutes**

with an A3 target of:

**≤65 minutes**

The target state shifts routine status needs toward self-service and proactive communication.

### Jira Execution

The improvement backlog was translated into:

- 1 Epic
- 6 User Stories
- 25 Jira work items
- 2 Sprint cycles represented in the execution evidence

Sprint 2 demonstrated:

**18 story points committed → 18 completed**
